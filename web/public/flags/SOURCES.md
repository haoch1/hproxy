# Flag assets

Two-letter country/territory SVGs use their intrinsic proportions from
[hampusborgos/country-flags](https://github.com/hampusborgos/country-flags).
The upstream project identifies the flag artwork as public domain.

Additional regional and organization flags retain the original
[flag-icons](https://github.com/lipis/flag-icons) artwork; see LICENSE for its MIT license.

Render these images with automatic width/height inside a fixed, centered icon slot.
Do not stretch the artwork to a shared aspect ratio.
